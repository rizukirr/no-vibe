# memory/

Archived versions of `NO-VIBE.md`. Created when:

- The user runs `/no-vibe-forget` (which resets `NO-VIBE.md` to default).
- AI replaces the whole file (rare; usually edits are surgical).

Filename: `NO-VIBE-<ISO-timestamp>.md`. Files here are write-once and never modified after creation.

AI does not load this directory automatically. It scans here only when the current `NO-VIBE.md` is empty AND you reference past context AI doesn't currently have. AI will surface a relevant line and ask before restoring it.

You can browse these files directly. To wipe everything (this folder included), run `/no-vibe-clear`.
